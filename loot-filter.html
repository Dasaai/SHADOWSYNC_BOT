Лут фильтр

Все иконки на карте могут мешать фильтру. Сейчас автолута нет, поэтому лучше использовать FilterMinimapIconCommenter.exe.

Программа

Автоматически редактирует .filter-файлы до рабочего состояния.

Скачать

FilterMinimapIconCommenter.exe

Видео

Открыть видео

Как пользоваться

  1. Запустите FilterMinimapIconCommenter.exe.
  2. Нажмите File -> Add Filter Files... или Add Files.
  3. Выберите один или несколько файлов с расширением .filter.
  4. Нажмите Process Files.
  5. Программа заменит строки, начинающиеся с MinimapIcon, на закомментированные.
