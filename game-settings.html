Настройки игры

Все настройки созданы на основе этого пресета. Рекомендуем использовать его, иначе система может работать некорректно.

Обязательное соответствие значений полей, отмеченных красным цветом. Слева находится фласка на HP, справа фласка на MP. Эти значения являются критически важными для корректной работы системы.
