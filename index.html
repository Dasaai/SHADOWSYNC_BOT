О программе

Follow Bot ShadowSync для Path of Exile 2 позволяет управлять дополнительными персонажами (ботами) с одного или двух ПК. Боты автоматически используют ауры, знамёна и другие способности, следуя за основным персонажем, чтобы усиливать урон, сопротивления, скорость и редкость выпадаемого лута.

1 Игрок + 1 Бот

Режим для одного ПК: вы управляете основным персонажем с клавиатуры, а бот управляет вторым персонажем на этом же компьютере.

  • Автоследование бота за игроком на карте.
  • Автонажатие способностей с настраиваемым интервалом.
  • Ручное нажатие клавиш для бота с клавиатуры игрока.
  • Автолечение для персонажа игрока и для бота.

1 Игрок + 2 Бота

Режим для двух ПК: два бота следуют за основным персонажем и работают как поддержка группы.

  • Автоследование двух ботов.
  • Индивидуальные настройки автонажатия кнопок для каждого бота.
  • Функция автолечения.
  • В разработке: авто лут и авто принятие квестов.

Выбор персонажа

Режим для настройки и выбора персонажей, которыми будет управлять бот.

Пример применения режима «1 Игрок + 1 Бот»: бот должен стоять на базе вместе с основным персонажем.

Пример применения

Вы можете создать мощную связку из двух персонажей на одном компьютере. Например: основной персонаж с уроном + бот-Хрономансер. Вы можете вручную нажимать клавиши на втором персонаже в критический момент или доверить это боту, настроив автоматическое применение способностей с нужным интервалом.

Для режима «1 Игрок + 1/2 Бота (2 ПК)» бот должен стоять на отдельном ПК или на VM. Для этого нужен 2 аккаунта с игрой.

Системные требования

  • Монитор: только 1920x1080 (Full HD) либо вручную выставленное разрешение Full HD.
  • Бот съедает 10-20 FPS в игре.
  • ОЗУ: минимум 8 ГБ.
  • Процессор: от 4 ядер / 8 потоков.
  • Видеокарта: от 4 ГБ видеопамяти.

Важно

  • Если железо слабее, не покупайте.
  • Динамическое разрешение пока не поддерживается, но будет добавлено позже.
  • Программа не вмешивается в игровой процесс и не читает память игры, минимизируя риск бана.
